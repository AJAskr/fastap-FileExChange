# fastapi轻量级文件中转站
## 介绍
```text
😈纯前端 + fastapi + sqlite
💻windows运行：
    1. 确保sqlite已经安装
    2. 直接启动fastapi服务
    3. 运行index.html服务在浏览器打开
👍这是一个简单方便的文件中转站项目，你可以轻松部署在任何任何服务器当中
👌实现 前后端分离 支持异步100+用户同时上传
✌️你可以把他当作一个临时的文件中转工具，或者练手的项目，暂时没有文件删除以及定时清理等功能
❤️喜欢记得点点Stars 感谢
```
## 文件描述
```text
frontend/index.html --这是前端文件，运行时需要另外启动，与后端分开
uploads             --用于存储用户上传的文件
files.db            --用户存储文件上传的描述信息
main.py             --后端核心逻辑
```
